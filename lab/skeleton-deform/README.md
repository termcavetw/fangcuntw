# 骨架變形（間架軸）

v258 新增的「間架」設計軸的原始碼與參考實作。原本的軸只改筆畫外觀（粗細、端點、質感），間架軸改的是字的骨架本身：撇捺的角度、主筆長短、白縫間距。

| 檔案 | 說明 |
|---|---|
| `skeldeform.js` | 正式版，原樣內嵌在 `index.html`（插在 `collectRenderStrokes` 之前）。改這裡之後要同步貼回 index.html。 |
| `deform2.py` | 早期的 Python 參考實作。最新的防撞規則（看實際畫出的弧線、拉直也交給防撞判斷）只做在 JS 版，兩者已不完全一致，以 JS 版為準。 |
| `experimental-styles.json` | 七種實驗字體的參數（電影海報、速度感、哥德、寬扁明、霓虹管、膨膨糖、招牌黑）。`base` 是起始預設，`params` 疊在上面。 |

## 六根軸

| 鍵 | 名稱 | 範圍 |
|---|---|---|
| `skspread` | 撇捺開合（依筆長漸入：150 以下不動、300 以上全量，點與短撇不會被轉） | −15°～15° |
| `skext` | 主筆伸展 | −0.3～0.4 |
| `skocto` | 斜筆幾何化（25°–65° 的斜筆吸到 45°，≥0.5 時弧線拉直） | 0～1 |
| `skvsnap` | 陡撇拉直（離垂直 N° 以內的撇拉成直豎） | 0～30 |
| `skdotv` | 點換短豎 | 0～1 |
| `skeven` | 白縫等寬（三條以上平行橫或豎的間距拉平） | 0～1 |
| `hgrid` | 橫線對齊（原本的骨架軸，v258 起改在骨架層做：橫畫吸到格線時，接在上面的筆端一起移） | 0～1 |

## 做法

1. 每一段筆畫給一個目標向量。
2. 在「接點不散、T 接不脫、交叉位置比例不變」的限制下，用最小平方法解出所有控制點的新位置。
3. 只套用參數造成的位移量，所以全部軸歸零時字形逐點不變。

變形後會跑防撞檢查，有問題就依序處理：

1. 讓撞到的彎筆保留原弧（不拉直）。
2. 把撞到的那幾筆變形量減半。
3. 整個字一起縮小變形量，用二分法找出不撞的最大幅度。

防撞檢查看這幾種情況：
- 不相干的筆交錯或擠在一起。
- 相連的兩筆被折成尖角。
- 相連的兩筆互相穿過去。
- 筆端跑到鄰筆實際形狀的另一側。

只作用在 KAGE 骨架的字；用楷體剖面資料（`kskel=1`）畫的字不受影響。
